# 勤怠入力簡略化システム

スマートフォンから簡単な操作で勤怠を記録できる、個人利用向けのPWA（Progressive Web App）です。

## フォルダ構成

```text
attendance_app/
├─ index.html          # 画面のHTML
├─ style.css           # 画面デザイン
├─ app.js              # 勤怠登録・履歴・設定などの処理
├─ manifest.json       # PWAとしてホーム画面に追加するための設定
├─ service-worker.js   # キャッシュ・オフライン対応
├─ icon-192.png        # PWA用アイコン（192×192）
├─ icon-512.png        # PWA用アイコン（512×512）
└─ README.md           # この説明ファイル
```

## 主な機能

- 「遅刻」の登録
- 「PM休」の登録
- 「終了時刻」のワンタップ登録
- 終了時刻を現在時刻から15分単位で切り捨て
- 通常勤務開始・終了時刻の設定
- 遅刻時の開始時刻設定
- PM休の開始時刻設定
- X/16～X/15の勤怠期間で管理
- 土日判定
- 祝日判定（2026～2027年分を初期搭載）
- 1か月分の履歴表示
- 今日の勤怠編集・削除
- 履歴画面から過去日の簡易編集
- 勤怠表へ貼り付けるためのタブ区切りコピー
- localStorageによる端末内保存
- PWA対応（ホーム画面からアプリのように起動）
- Service Workerによるキャッシュ対応

## ファイルごとの役割

### index.html
画面の骨組みを定義します。
入力・履歴・設定の3画面、ボタン、編集モーダルなどを配置しています。

### style.css
スマートフォンで操作しやすいように、ボタン・カード・入力欄・下部ナビゲーションなどの見た目を定義しています。

### app.js
このアプリのメイン処理です。
ボタン操作、勤怠データの保存・読み込み、勤怠期間の計算、休日判定、履歴表示などを担当します。

### manifest.json
PWAの名前、アイコン、起動方法などを定義します。
`display: standalone` により、対応ブラウザではホーム画面からアプリらしい表示で起動できます。

### service-worker.js
アプリに必要なファイルをキャッシュします。
一度読み込んだファイルを利用できるようにし、ネットワーク接続がない場合でもアプリを開きやすくします。

## 起動方法

### ローカルで確認する場合

`index.html` を直接開く方法でも画面確認はできますが、PWAのService Workerは通常HTTPSまたはlocalhost環境が必要です。

VS CodeのLive Serverなど、ローカルサーバーを使って確認する方法がおすすめです。

### GitHub Pagesで公開する場合

1. GitHubにリポジトリを作成
2. このフォルダ内のファイルをアップロード
3. GitHubの `Settings` → `Pages` を開く
4. `Deploy from a branch` を選択
5. `main` ブランチ・ルートフォルダを指定して公開
6. 発行されたURLをスマートフォンで開く
7. ブラウザの「ホーム画面に追加」などからPWAとして登録

## データについて

勤怠データと設定値は `localStorage` を利用して、このブラウザ・端末内に保存します。
サーバーへ勤怠データを送信する仕組みはありません。

そのため、ブラウザのデータ削除や端末変更などによってデータが消える可能性があります。
実際の業務利用をする場合は、会社の勤怠ルールや保存要件を確認してください。
